## Glossary

| Term | Meaning |
|---|---|
| API gravity | density scale for crude; higher means lighter |
| BS&W | basic sediment and water |
| CDU / VDU | crude (atmospheric) distillation unit / vacuum distillation unit |
| Claus process | converts H₂S into elemental sulfur |
| Demulsifier | chemical that breaks oil-water emulsions |
| FCC / RFCC | fluid catalytic cracker / residue fluid catalytic cracker |
| HDT, HDS | hydrotreater, hydrodesulfurisation |
| MDEA | methyldiethanolamine, an amine that absorbs H₂S |
| Merox | process that oxidises mercaptans to disulfides |
| OEB | Oman Export Blend crude |
| PSA | pressure swing adsorption (hydrogen purification) |
| ptb | pounds of salt per thousand barrels (1 ptb ≈ 2.85 mg/L) |
| Pumparound | heat-removal loop on a distillation column |
| RON | research octane number |
| SDA | solvent deasphalting |
| SMR | steam methane reforming |
| SRIP | Sohar Refinery Improvement Project |
| SRU | sulfur recovery unit |
| TAN | total acid number |
| TBP | true boiling point distillation (crude assay) |
| ULSD | ultra-low-sulfur diesel (≤ 10 mg/kg S) |
| VGO | vacuum gas oil |
| VLSFO | very-low-sulfur fuel oil (≤ 0.50 wt% S) |
